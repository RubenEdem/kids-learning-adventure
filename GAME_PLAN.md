# Kids Learning Adventure — Game Plan

A beginner-friendly Android learning game for children aged 5–8, built with MIT App Inventor.

## First version

The first version will work offline and will not collect children's personal information.

### Activities
1. **ABC Learning** — show a letter and let the child choose the matching letter.
2. **Math Stars** — counting and simple addition/subtraction.
3. **Animal Quiz** — show an animal name or picture and choose the correct answer.
4. **Stars and encouragement** — award a star for a correct answer and use friendly feedback.

## Build order

1. Create the app project in MIT App Inventor.
2. Build the home screen with three activity buttons: ABC Learning, Math Stars, and Animal Quiz.
3. Build and test one activity at a time.
4. Test on an Android phone or emulator.
5. Add sound and images after the basic activities work.
6. Consider a backend only if online accounts, cloud saves, or leaderboards are truly needed.

## Child privacy and safety

- Keep the first version offline.
- Do not ask children for their names, phone numbers, location, or other personal information.
- Avoid ads, chat, public profiles, and external links in the child-facing app.
- Ask a parent or guardian to test the app before children use it.

## Important note about source code

MIT App Inventor projects are normally exported as an `.aia` file. This GitHub repository can hold the project plan, documentation, and any backend source code added later. The first offline game does not need a backend.
